## Steps

### Step 1 — recap data on the server

No secret goes into the recap: it reads the public events (seed removed, `publicEvent`), names come from the live view's name map, and it lists no card and no undrawn number. A round end and a cut already make every screen fetch its state (they are not appendable frames), so the recap needs no new socket message; host, players, eliminated players and spectators fetch the same state.

Lines before → after: `matches.ts` 149 → 168 (the state route moved into its own function for the 60-line limit), `matchViews.ts` 129 → 134, `liveViews.ts` 69 → 108, `matchViews.test.ts` 134 → 136, `liveViews.test.ts` 75 → 76, contracts `clientView.ts` 160 → 164, contracts `index.ts` 55 → 56; new `roundRecap.ts` 266, `roundRecap.test.ts` 261, `roundRecap.integration.test.ts` 108, contracts `roundRecap.ts` 45. Reused: the domain's `evolve` and `createInitialMatchState`, `publicEvent`, the live view's shared replay and name map, the stored `occurredAt` of each event, `sbr.marks`, the ruleset helpers `defaultRulesetFor`/`toMatchRuleset` in tests, the integration harness and the HTTP tap route. Tests: server view and route units 18 green, recap integration 1 green.

### Step 2 — the interlude screen

The cut screen (D15) stays first and leads into the recap below it; the host's Start next round stays above the recap. The cards are keyed by card, so each new card fades in (`sbr-anim-fade` from motion.css), and not at all under prefers-reduced-motion. Extracted: `components/Podium.tsx` from `FinalPlacement` (the final placement and the top-three card share it). Reused: `RankRow` (climber), `SeasonIcon`, `useSecondsUntil` (the countdown), `useReducedMotion`, the `podium`, `rank-list` and panel styles, the labels module's `seasonCompleteLine`.

Lines before → after: `FinalPlacement.tsx` 101 → 98, `RankRow.tsx` 68 → 68, `MatchScreen.tsx` 203 → 217, `HostConsole.tsx` 163 → 176, `labels.ts` 170 → 206; new `Podium.tsx` 42, `Interlude.tsx` 152, `InterludeCards.tsx` 136, `interludePlan.ts` 73, `interlude.css` 72, `interlude.test.tsx` 215. A first version of the two timing tests advanced the fake clock by several card times in one step, which React cannot follow (each card's timer starts after it is shown); the tests now advance one card time at a time.

### Step 3 — pause length

The first version used 4 s per card, from a rough guess of 8–15 words a card. Rendering a full recap and counting its words showed the cut and seasons cards hold about 20, so 4 s would rush them; it is now 5 s, and the spec says so. Lines before → after: `interludePlan.ts` 73 → 75, `interlude.test.tsx` 215 → 215, spec 01 one number. The measuring test was scratch and is deleted.
