## NEEDS THE OWNER'S WORD

- **Shortest timed draws in the Quick Test** are now the speed window plus one second (4 s with the 3 s default window), so a window always closes before the next draw (D10). The ruleset already requires the window to be shorter than the draw interval; the extra second is a choice.
- **A missed number of a round's last draw** under "mark for me after 3 seconds" is marked at the moment the window closes; the server counts it (inclusive), and the Quick Test card may show the round end first.
- `docs/OPEN.md` said WP-09 was on a branch `feat/wp-09-accounts`; no such branch exists. Corrected.
- **Pre-session calls without a CSRF token**: register, login, guest and dev sign-in cannot carry the per-session token yet; they accept only JSON bodies, which no cross-site form can send. Written into 03 §8.
- **Dev cookie**: on plain-http development the cookie is `sbr_session` without Secure; production uses `__Host-sbr_session` with Secure, as 03 §3 says.

- **Match persistence at draft depth**: rounds, cards, draws and prize awards stay in the event log (their own tables are backlog); the match stores its frozen ruleset document instead of a ruleset version id (versions come with the admin panel); manual marks go through the aggregate instead of the off-aggregate path of 02 §5.4 (fine for 20 players, backlog for 200).
- **Pause between rounds**: 6 seconds after a round ends (cut screen) before the next round starts; not in the spec.
- **Host Draw next waits for the window**: a host draw is refused while the previous draw's speed window is open, so windows never overlap (D10).
