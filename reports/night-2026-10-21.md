## NEEDS THE OWNER'S WORD

- **Shortest timed draws** are the speed window plus one second (4 s with the 3 s window), in the Quick Test and the real game, so a window always closes before the next draw (D10). The ruleset already requires the window to be shorter than the draw interval; the extra second is a choice.
- **A missed number of a round's last draw** under "mark after 3 seconds" is marked at the moment the window closes; the server counts it (inclusive).
- **Host Draw next waits for the window**: refused while the previous number's speed window is open, so windows never overlap.
- **Pause between rounds**: 6 seconds after a round ends (cut screen) before the next round starts; not in the spec.
- **Start rule**: the host starts the match; players see a 10-second countdown. Time-based and when-full starts are backlog.
- **Match persistence at draft depth**: rounds, cards, draws and prize awards stay in the event log; the match stores its frozen ruleset document instead of a ruleset version id; manual marks go through the match aggregate rather than the separate path of 02 §5.4 (fine for 20 players, to revisit for 200).
- **The live screen refetches the view on every event frame** (only the new events, plus the players and owner status); fine for 20 players, heavier for 200.
- **Pre-session calls without a CSRF token**: register, login, guest and dev sign-in accept only JSON bodies (no cross-site form can send JSON). Written into 03 §8.
- **Dev cookie**: `sbr_session` without Secure on plain-http development; production uses `__Host-sbr_session` with Secure (03 §3).
- **A stray dev server on 5173**: during the night an older Vite process restarted itself after a config change and came back on 5173 (a forbidden port); it was stopped and the client restarted on 5390. The config keeps `strictPort` on 5390.

## FOR THE OWNER

**The game runs at http://localhost:5390** (branch `feat/real-game-draft`, not merged; the Quick Test is merged into `master`).

**Try it alone**

1. Open http://localhost:5390 in a normal window. Press **Sign in as host**, then **Host a match** in the top bar.
2. Choose a game type (royale, classic with seasons, or classic), the prizes for classic games, how numbers are drawn (**Draws: timed (every N seconds)** or **Draws: host presses Draw next**) and what happens to missed numbers. Press **Create match**. You land on the host console with the match code.
3. Open one or two **private windows** (each private window is a separate person). In each, press **Sign in as player 1** (or 2, 3), find the match in the lobby and press **Join**. You see the waiting room.
4. Back in the host window: **Fill with bots** (bots mark automatically) and **Start match**. Players see a 10-second countdown, then the arena.
5. With host draws, press **Draw next** (or the Space key). It opens again when the last number's 3-second speed window has closed. You can switch between **Timed draws** and **Host draws** and change the seconds at any time.

You can also play without players: create a match, fill it with bots, start it, and watch from the host console.

**On the player screen**: the current number large with its letter, a bar that runs down for the 3-second speed window, the numbers drawn so far, your card (tap a number when it is drawn; a tap inside the window earns a speed bonus; the last number of a round can still be tapped inside its window), your points, rank, effects, seasons and shield, the standings with players still in the match first, the prize list in classic games, the cut screen, and the final ranking.

**On the host console**: the joined players before the start, then the current and recent numbers, Draw next, the draw switch, the standings, the prizes awarded, the match log with cut results, and Abort with a reason.

**The Quick Test** now lives at http://localhost:5390/#/quicktest (link "Quick Test" in the top bar).

**Not done and open questions**: see NOT DONE and NEEDS THE OWNER'S WORD above. Most visible: there are no register or sign-in forms yet (only the development sign-in buttons), and pause and start rules by time are not built.
