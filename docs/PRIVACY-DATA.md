# What the game stores about a player

Every item Seasonal Bingo Royale keeps per player, for the operator's privacy page. Two kinds of install exist: **standalone** (the game's own accounts) and **website** (embedded in the Seasonal Entertainment website; players sign in with their website account). "Deleted when" means: when the player deletes their account in the game (DELETE /me), or in website mode also when the website reports the account as deleted (its account-changes feed).

The game stores no real name, no address, no IP address and no payment data in either mode. Backups (encrypted with the operator's key) contain the same data for up to 14 days (daily) and 8 weeks (weekly) and then expire.

## Both modes

| Table                             | Field                                                                                         | Purpose                                                      | How long                                                                    | Deleted when                                                                                     |
| --------------------------------- | --------------------------------------------------------------------------------------------- | ------------------------------------------------------------ | --------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| `accounts`                        | display name                                                                                  | shown in matches, standings, the leaderboard and the profile | while the account exists                                                    | account deleted                                                                                  |
| `accounts`                        | created, updated, last sign-in times                                                          | account housekeeping                                         | while the account exists                                                    | account deleted                                                                                  |
| `accounts`                        | status (active, suspended)                                                                    | lets an admin suspend an account                             | while the account exists                                                    | account deleted                                                                                  |
| `sessions`                        | hashed session token, CSRF token, browser name (user agent), created, last seen, expiry times | keeps the player signed in                                   | until the session expires or is revoked, then deleted by the daily clean-up | account deleted, sign-out, or expiry                                                             |
| `role_assignments`                | the player's roles (player, host, admin)                                                      | what the account may do                                      | while the account exists                                                    | account deleted                                                                                  |
| `match_entries`                   | which matches the player joined, points, place, effects                                       | the match results and histories                              | kept with the match                                                         | account deleted: the link to the account is removed; the points stay under "deleted player xxxx" |
| `match_events`                    | the internal account id (a random number) in the events of a match                            | the match's verifiable record (append-only)                  | kept with the match                                                         | never rewritten; after deletion the id no longer leads to an account or a name                   |
| `marks`                           | each cell the player marked, with the time it was received                                    | scoring and the speed bonus                                  | 90 days, then deleted                                                       | account deleted: kept without a link to an account until the 90 days end                         |
| `standings`                       | the player's points per match                                                                 | live standings                                               | kept with the match                                                         | account deleted: kept without a link to an account                                               |
| `league_entries`, `league_awards` | league points, wins, Season Completes per season                                              | the leaderboard                                              | while the account exists                                                    | account deleted (the player leaves the leaderboard)                                              |
| `badges_awarded`                  | badges the player earned                                                                      | the profile                                                  | while the account exists                                                    | account deleted                                                                                  |

## Standalone mode only

| Table      | Field                                        | Purpose                               | How long                 | Deleted when    |
| ---------- | -------------------------------------------- | ------------------------------------- | ------------------------ | --------------- |
| `accounts` | e-mail address                               | sign-in and account messages          | while the account exists | account deleted |
| `accounts` | password hash (Argon2id; never the password) | sign-in                               | while the account exists | account deleted |
| `accounts` | e-mail verified time                         | league points need a verified address | while the account exists | account deleted |

## Website mode only

| Table                 | Field                                                                      | Purpose                                         | How long                                            | Deleted when                                                |
| --------------------- | -------------------------------------------------------------------------- | ----------------------------------------------- | --------------------------------------------------- | ----------------------------------------------------------- |
| `external_identities` | the website's user id (an opaque number)                                   | links the website account to the game account   | while the account exists                            | account deleted                                             |
| `external_identities` | the website name, roles and "may start games" of the last sign-in          | notices a name change; hosting and admin rights | while the account exists                            | account deleted; replaced at every sign-in                  |
| `accounts`            | "e-mail verified" time (the website's good standing; no address is stored) | league points                                   | while the account exists                            | account deleted                                             |
| `accounts`            | Discord steps (up to three: ladder, step name, icon path)                  | shown next to the name, as on the website       | while the account exists; replaced at every sign-in | account deleted (also when the website deletes the account) |
| `website_deleted`     | the website's user id of an account the website deleted                    | refuses a later sign-in with that id            | permanently                                         | never (it holds nothing but the website's opaque id)        |

The game asks the website for no other data. A rename on the website shows from the player's next sign-in. A change on the website (deleted, locked, unlocked, rights) ends all the player's game sessions within about 2 minutes. In website mode a game session lasts at most 7 days.
