## 8. Needs the owner's word

- **HSTS on the game's own answers in a website install.** The game sends none (`apps/server/src/http/plugins/securityHeaders.ts:45`; spec 03 table: "a website install relies on the website's proxy"), and the website's Caddy adds it only to its own pages. A browser that has seen any website page keeps HSTS for the whole host for a year, so a visitor who comes through the website is covered; one who opens `/games/bingo/` first gets the 308 redirect but no HSTS until a website page. Proposal: the website adds the header for the imported game routes too (website repository), or the game's route file adds it (`ops/lib/websiteRoute.sh`) with the website's value. Not changed tonight (the website owns the host's policy; the website repository is read-only here).

## 9. Noticed, left alone

- The guest and member cookie carries `Max-Age=2592000` (30 days) in website mode, where the server ends a session after 7 days (`apps/server/src/auth/sessions.ts`): the server decides; the cookie only outlives it. **Fixed on master (PR #66, 2026-11-23):** the cookie's `Max-Age` is the session's absolute length of the running mode, 7 days in website mode, 30 standalone (`apps/server/src/auth/sessionPlugin.ts` `setSessionCookie`). **Decided by the owner (2026-11-23):** an admin's session cookie may outlive the 8-hour admin session (it follows the player length of the running mode); no change, the server ends the session.
- osv-scanner warns that `ignoreUntil` is deprecated in favour of `effectiveUntil`; with no entry left this no longer applies.
